## Findings considered and rejected

So nobody re-audits them. Each was opened against the code, or probed on `next.rahlwes.eu`, and found wrong or not worth a plan.

- **Imprint page 404s / footer link broken**: false. `/impressum/` and `/datenschutz/` return 200; the footer links `/impressum/` with `hreflang="de"` on purpose (legal pages are German-only).
- **`npm run rephrase` targets a missing script**: false. `scripts/rephrase.mjs` exists.
- **English project translations cover 3 of 10**: false. en and fr both have all 10 project files.
- **`serveMedia` mishandles suffix ranges (`bytes=-N`)**: false. Probed: `206`, `Content-Range: bytes 17673697-17673796/17673797`, a 100-byte body identical to the file tail.
- **Admin gate is hammered by bad tokens (SEC-06)**: speculative. No evidence of GitHub throttling; the 60 s grant cache is a decided tradeoff in `src/middleware.ts` and `README.md`.
- **Anyone can unsubscribe any address (SEC-08)**: by design. `src/pages/api/newsletter/unsubscribe.ts:37-38` and the address form on `/newsletter/abmelden/` exist for readers who no longer have a mail. A deletion is low-impact and the alternative adds a send.
- **Newsletter signup has no captcha (SEC-09)**: the per-IP limit plus the one-hour per-address cooldown is the tradeoff recorded in `wrangler.jsonc:29-31`.
- **Subscriber emails in logs (SEC-10)**: one `console.error` on a rejected address; low value, kept in view only if observability retention is ever reviewed.
- **JSON-LD `@id` is hard-coded to `rahlwes.eu` on staging**: deliberate stable identifiers (`src/i18n/schema.ts:6-7`); `url` fields follow `site`. Correct as written.
- **`NewsletterForm` uses fixed element ids**: latent; one instance per page today.
- **`Env` double casts in the archive-search routes; an untyped `children` prop in `BlockQuote`**: cosmetic.
- **CI heredoc injection via scraped fields (SEC-12)**: not feasible, the scraper's only stdout write is one line of `JSON.stringify`.
- **Image weight**: `dist/client/_astro` is 52.5 MB, but every content image ships a `srcset` and 20 of 21 on the heaviest page are lazy-loaded. Browser transfer was not measured, so no claim either way; not worth a plan without a Lighthouse run.
